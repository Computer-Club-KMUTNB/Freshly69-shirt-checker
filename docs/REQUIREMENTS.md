# Requirements — ระบบยืนยันการรับเสื้อเฟรชชี่ ปี 69

สรุปจากการเก็บ requirement รอบ 1 (25/11/69) + การคุยรอบต่อมา (26/11/69)

## ความต้องการหลัก
- ตรวจได้ว่าผู้มารับเป็นนักศึกษาปี 1 ที่อยู่ในรายชื่อ (กรอกฟอร์มไซส์เสื้อไว้)
- ตรวจสถานะได้ว่าคนนี้รับเสื้อแล้วหรือยัง (รับได้คนละ 1 ครั้ง)
- ใช้บนมือถือได้สะดวก ไม่ต้องมีอุปกรณ์เพิ่ม (ใช้กล้องมือถือสแกน)
- ตรวจคณะของผู้มารับได้ (แต่ละคณะรับคนละวัน → สตาฟเลือกคณะที่โต๊ะกำลังแจก)
- ไม่ต้องระบุตัวสตาฟรายคน แต่ต้องเก็บข้อมูลเครื่องที่ใช้

## วันเวลา / สถานที่
2–4 และ 8–9 ธันวาคม 2569 · 16:00–20:00 น. · ใต้สนามกีฬาลอยฟ้า

## ขั้นตอนหน้าสแกน
1. เลือกคณะที่กำลังแจก
2. กดปุ่มเปิดกล้อง (ปุ่มใหญ่เด่น) หรือพิมพ์รหัส 13 หลัก (สำรอง — มีทั้งในหน้าหลักและในหน้ากล้อง)
3. กล้อง: แฟลช, เปลี่ยนเลนส์, ซูม, แตะเพื่อโฟกัส; เปิดค้างไว้สแกนคนต่อไปได้เลย
4. ระบบแสดงสถานะ (ดูตาราง) → กด **ยืนยันแจก**
5. ข้อความ "ยืนยันแจกเสื้อสำเร็จ" + ปุ่ม **แก้ไข** (ยกเลิกรายการแล้วทำใหม่) คู่กับปุ่ม **เสร็จสิ้น**

การสแกน/ค้นหาถูกบันทึก log ทันทีพร้อมเวลา แต่จะนับว่า "แจกแล้ว" ก็ต่อเมื่อกดยืนยันเท่านั้น
(สแกนแล้วไม่ยืนยัน = ยังไม่แจก และขึ้นในภาพรวมว่า "สแกนแล้วยังไม่ยืนยัน")
